# ДЕКОРАЙ · отзывы покупателей

Посетитель подбирает архитектурные панели. Блок помогает быстро прочитать отзывы и увидеть фотографии монтажа, если их приложили покупатели.

## Направление

Два варианта сверены с владельцем в чате: карусель из двух карточек и лента по одному отзыву на строку. Владелец выбрал ленту по примеру на светлом фоне и попросил сделать стиль мягче. Использованы порядок «общая оценка → вложения → отзывы» из загруженного примера и типографика, тёплые цвета и спокойная сетка из макета ДЕКОРАЙ. Обе композиции просмотрены в чате. Дополнительный [референс по медиавложениям](https://judge.me/help/en/articles/12460582-customizing-the-review-widget-new-version) изучен по документации. График распределения и элементы сбора отзывов не используются.

Существующие цветовые и шрифтовые токены. Общая оценка выделена тёплым светом, короткие строки в списке отделены тонкими рамками с небольшим радиусом. На узком экране информация об авторе переходит наверх. Сначала видны три отзыва, остальные открываются по кнопке. Фото открывается в нативном диалоге.

## Данные и выпуск

Карточки показывают только подтверждённые данные из публичного снимка. При отсутствии фотографий галерея скрыта, при отсутствии аватара используются инициалы или значок. Pages использует изолированное тестовое окружение. Рабочий хостинг вне этого изменения.
