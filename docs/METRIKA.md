# Яндекс Метрика для ДЕКОРАЙ

Основной адрес — `https://xn--80ahdrdyo.xn--p1ai/` (декорай.рф). Публичный номер счётчика: `114347066`. Для сборки передайте `VITE_YM_ID=114347066` в окружение Vite. Без переменной сборка работает без аналитики.

## Настройки счётчика

В кабинете Метрики в настройках счётчика укажите адрес `декорай.рф`. Оставьте выключенными автоматические цели, автоматический сбор контактных данных, Вебвизор, карту скроллинга и аналитику форм. Сохраните настройки. Код сайта загружает один скрипт после согласия посетителя. При отзыве согласия счётчик останавливается и страница перезагружается; уже переданные сервису события сохраняются у провайдера.

Для каждого пункта ниже выберите «Цели → Добавить цель → Целевое событие», затем условие «совпадает» и точный идентификатор.

| Название | Идентификатор | Когда срабатывает |
|---|---|---|
| Открытие каталога | `catalog_view` | Переход на страницу каталога |
| Карточка товара | `product_view` | Открытие карточки или выбор другой открытой карточки |
| Добавление в подборку | `cart_add` | Допустимое добавление товара в подборку |
| Результат калькулятора | `calculator_complete` | Первый корректный расчёт с выбранным материалом |
| Завершение квиза | `quiz_complete` | Показ результата после последнего ответа |
| Переход в Telegram | `telegram_click` | Клик по ссылке Telegram |
| Клик по телефону | `phone_click` | Клик по ссылке звонка |
| Подтверждённая заявка | `lead_submit` | Backend подтвердил сохранение заявки |

## Проверка после размещения

1. Откройте production в новом профиле браузера. До согласия и при отказе запросов к тегу Метрики быть не должно. Виджет Яндекс Карт проверяйте отдельно.
2. Разрешите аналитику. Убедитесь, что тег загружается один раз, номер счётчика совпадает, а переключение между страницами каталога и политики вызывает по одному просмотру. Фильтрация в каталоге не считается новым просмотром.
3. Откройте карточку, добавьте товар, завершите расчёт и квиз, нажмите Telegram и телефон. В запросах событий проверьте идентификаторы целей и отсутствие содержимого формы, ссылки на черновик, номера телефона и имени. Протестируйте `lead_submit` после допуска формы на отдельной согласованной заявке. Переходы в Telegram, ошибки отправки и тайм-ауты не должны давать эту цель.
4. Отключите аналитику в политике. Проверьте, что при перезагрузке скрипт не входит в сетевые запросы. Подтвердите регистрацию тестовых событий в отчёте Метрики.

Локальная проверка поведения адаптера: `node --test scripts/analytics.test.mjs`. Она проверяет вызовы адаптера без сети. Привязку кабинета и реальный трафик подтверждают проверки выше.

Документация Яндекса: [настройки счётчика](https://yandex.ru/support/metrica/ru/general/counter-general.html), [SPA](https://yandex.ru/support/metrica/ru/code/counter-spa-setup), [целевые события](https://yandex.ru/support/metrica/ru/general/goal-js-event), [проверка цели](https://yandex.ru/support/metrica/ru/general/check-goal.html).
