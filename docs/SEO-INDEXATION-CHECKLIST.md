# Домэра: SEO и индексация

## Repository-ready

- [x] Единственный серверный HTML-документ — `/`; canonical, OG URL, JSON-LD URL, robots и sitemap указывают на `https://xn--80ahyhl1f.xn--p1ai/`.
- [x] Sitemap перечисляет только корень. `#/catalog`, `#/privacy`, `#/offer` — клиентские состояния фрагмента URL, а не отдельные HTTP-страницы. Для них не создаются фиктивные sitemap/canonical адреса.
- [x] Статический `<head>` содержит русскоязычные title/description, Open Graph и social card с существующим изображением 1200 × 630. При навигации React обновляет title/description для удобства посетителя.
- [x] `robots.txt` разрешает обход документа и ресурсов. Production verifier проверяет адреса, файл OG, метаданные и состав sitemap в `dist/`.
- [x] В коде нет токенов подтверждения прав на домен и нет автоматической отправки sitemap в поисковые сервисы.

## OWNER INPUT REQUIRED после production deploy

- [ ] Подтвердить работоспособность HTTPS, единственный canonical hostname и ответы 200 для `/`, `/robots.txt`, `/sitemap.xml`, OG image, JS/CSS и шрифтов на реальном хостинге.
- [ ] Добавить `домэра.рф` в Яндекс Вебмастер. При необходимости добавить в Google Search Console. Подтвердить права способом, поддерживаемым сервисом и доступным на выбранном хостинге; токен хранить и размещать только после получения от владельца.
- [ ] Отправить фактический `https://домэра.рф/sitemap.xml`, проверить его обработку, robots и canonical в инструментах вебмастера.
- [ ] Проверить фактическую индексацию корневого документа, отображаемый сниппет и Open Graph preview на опубликованном домене. Отправка sitemap не гарантирует индексацию.
- [ ] Проверить, что GitHub Pages preview не выбран как основной результат поиска; canonical в preview указывает на production, но решение поисковой системы нужно подтвердить после запуска.
- [ ] Если бизнесу нужны отдельные индексируемые страницы каталога, товаров и документов, спланировать clean URLs после проверки возможностей REG.RU. Текущий hash-router не обеспечивает им отдельные HTTP-документы.

Никаких DNS, server rewrite и production-публикации этот checklist не выполняет.
